## 1. 现场判断（双方已对齐的部分）

- **判据不是解**：这套系统的证据只回答"这一条做完了没有"，从不回答"系统在变好还是变坏"。
  证据越多，越把我训练成执行者。这是我说错的一半。
- **刹车没有落盘**：人每次喊停（"先别自动化""乱成一锅粥了""不要再加机制"）只发生在对话里，
  从不进仓库。下一轮读到的是一份干净的账本：任务都交付、测试都绿、结论都通过——账面上没有
  任何证据说明系统正在烂，于是默认动作永远是"继续加功能"。
- **三层分工**：判据解决"能不能证明"，记忆解决"要不要想起"，闸解决"来不来得及停"。deed 现在只有第一层。

## 2. 这个样本为什么值得当样本

- 加一条事件，`74673eb` 动了 16 个文件；把"出清单"收成面板按钮，`d48ab61` 动了 23 个文件（+402/-203）。
- `EVENT_VERSION` 到 37；`core/fold.mjs` 一个函数里塞着重放、判定、携带、关闭、作废五种职责；
  `core/rules.mjs` 同时管策略与投影。
- 结论：**改动半径在涨**——这不是形容词，是可算的数（账本里每条提交都记了触及路径）。

## 3. 早期分析的存量结论（只记得结论，细节没留）

七条信号收敛成三根因：**A 事实没有唯一主人 / B 边界不显式 / C 约定不可检查**。
（当时的逐条记录没有落到本仓库，这一步要重新取证。）

## 4. 三个最小机制（按"咬人程度"排序，尚未实现）

1. **刹车记录**：每次人喊停，落一条事实（谁停的、停的是什么、涉及哪一层）；下次同类改动要说明
   这次与上次被停的那件事有什么不同。
2. **变化半径体检**：按账本算每个模块被改次数、每次机制改动拉多少文件；热点文件即病灶候选。
   它只报数，不判断。
3. **拆 `fold` / `rules`**，验收标准用第 2 条的数**下降**。

## 5. 重构的目标形态（本文档的核心，待定稿）

约束来自"手感"：**改一处要读几个文件 = 真实成本**。目标：新增/改一条事实，只碰两三个文件。

```
core/
  events/<域>.mjs        一个域一个文件：这些 kind 的定义、校验、版本语义
  replay/index.mjs       只遍历与分发，不含业务
  replay/reducers/<域>.mjs  该域的 case，纯函数 (session, ev, ctx) => void
  policy/<问题>.mjs      只回答一个问题（该不该审、过期没、下一步是谁、能不能签）
  facts/<域>.mjs         纯查询
lib/                     存储、版本、面板
cli/                     只做 io 与话术
board/                   只渲染
```

判据：新增一条事件 = `events/<域>.mjs` + `replay/reducers/<域>.mjs` + 注册表一行 + 该域的用例。

**评论区里站得住的判断**（按赞排序，原文摘录）：

- 赞 379：「我的第一反应竟然是，如何通过提示词让 ai 写出有设计的代码」——默认的人把"架构"当成提示词的产物。
- 赞 446：「你告诉 AI，给我完成某个功能，它就只会给你完成功能。你告诉它，注意应用架构和分层设计，
  它也会给你做分层设计，并且不比架构师做的差」——能力在，主动性不在。
- 赞 280：「AI 的架构设计与架构遵从能力并不弱，只是**不提醒的话其不会主动探索架构并遵从**，
  通常是 AGENTS.md 提醒 + 每次提交时审查」——提醒与人工审查是当前唯一的约束。
- 赞 80：「并非为 0，你需要让它先从业务需求文档开始理解，然后出设计，并把设计里的点按
  实现复杂度/可扩展性/可诊断性/吞吐量/安全性/自审一遍并报告操作员确认……」——流程化，但审的人还是人。
- 赞 202：「实际开发中 service 层和 domain 层才是最容易变的层」。
- 赞 67：「我让 ai 写，ai 写一大堆东西出来，看都懒得看了」——产出量与可读量失衡。
- 赞 64：「up 说的案例完全就是 SOLID……架构设计可以扩展到 组合优于继承 / AOP / 事件驱动 /
  插件化 / 状态机」。

**对我们的意义**：这些共识的隐含前提是"有一个 vigilance 的人逐次审"。我们的样本证明：
一旦这个人的注意力不在，架构就腐烂（deed 两轮改动 16/23 个文件）。所以给 agent 的架构不能停在
"提醒它"，必须把提醒变成**会自己红的约束**；SOLID 的每一条都要能翻译成一条可检测的规则，
否则它对 agent 等于不存在。
